# MaoLifeExpectancy

Charts on life expectancy in China and elsewhere during the Mao era (1950–1976), built from UN World Population Prospects 2024 data. Every chart and data file here is generated by code in this repository.

Each chart is a standalone interactive page published with GitHub Pages (served from `docs/` on `main`).

## Data

[`data/life-expectancy-gains-1950-1976-un-wpp2024.csv`](data/life-expectancy-gains-1950-1976-un-wpp2024.csv) has one row per UN country/area: life expectancy in 1950 and 1976, the change, 1950 population (thousands), whether it is in the scatter chart (`in_scatter`: 1m+ people in 1950, excluding Cambodia, Lebanon and the two Koreas), and the fitted change from the OLS line (`fitted_gain`).

**Source:** UN DESA Population Division, [World Population Prospects 2024](https://population.un.org/wpp/downloads?folder=Standard%20Projections&group=CSV%20format), Demographic Indicators file (medium variant), column `LEx` (life expectancy at birth, both sexes).

## Reproducing everything

```bash
pip install -r requirements.txt
python scripts/build_charts.py
```

The script downloads the UN file (~16 MB) to `data/raw/` (git-ignored) on first run, then rewrites the three HTML charts in `docs/` and the CSV in `data/`.

- [`scripts/build_charts.py`](scripts/build_charts.py) – computes every series, the regression and the chart notes from the UN data.
- [`scripts/chart_template.html`](scripts/chart_template.html) – the shared chart renderer; the script injects each chart's title and `CHART` config (the data) into it.

The three charts regenerate byte-for-byte identical to the originals. The one small difference is in the CSV's `fitted_gain` column, which can differ by up to 0.03 years from the original file (the fit is computed on the rounded values that are plotted).
